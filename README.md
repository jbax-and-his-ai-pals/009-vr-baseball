# VR Baseball

A pitching-first VR baseball game for Meta Quest 3, built in Godot 4.7 (OpenXR, mobile renderer). Fictional league, cartoony art.

## Run

- Desktop, no headset: `tools/godot.sh --xr-mode off`
- Tests: `tools/test.sh`
- Performance gate: `tools/perf.sh --demo --budget`
- Screenshots: `tools/shot.sh <view> --demo`
- Quest build: see `docs/QUEST.md` (untested)

## Docs

- `DESIGN.md`: design and architecture
- `ROADMAP.md`: what is done and what is left
- `docs/PLAYTEST.md`: headset playtest checklist and first-guess tuning values
